# Marathi NLP Analysis - Streamlit App

Interactive web application for analyzing Marathi text using lexicon-based NLP techniques including sentiment analysis, emotion detection, POS tagging, named entity recognition, TF-IDF analysis, and topic modeling (LDA).

## Features

- **Tokenization**: Devanagari-aware text tokenization
- **Sentiment Analysis**: Lexicon-based positive/negative/neutral detection
- **Emotion Detection**: Identify 10 emotions (joy, anger, sadness, fear, surprise, disgust, trust, anticipation, love, pride)
- **POS Tagging**: Heuristic part-of-speech tagging for Marathi
- **Named Entities**: Extract entity candidates from text
- **TF-IDF Analysis**: Find most important terms in input text
- **Topic Modeling**: LDA-based topic distribution analysis

## Setup Instructions


### 2. Generate Required Models (if not already present)

If you don't have the `.joblib` and `.json` model files, run the last cell of `NLPFINALSEM.ipynb` to export them:

## Usage

1. **Enter Text**: Type or paste Marathi text in the input box
2. **Load Examples**: Use the dropdown to load pre-defined example texts
3. **Click Analyze**: Press the "🔍 Analyze" button to process the text
4. **View Results**: Scroll through the analysis sections to see:
   - Token list and count
   - Sentiment score, label, and gauge visualization
   - Emotion word counts and dominant emotion
   - POS tags and distribution chart
   - Named entities extracted from text
   - TF-IDF top terms bar chart
   - LDA topic distribution and dominant topic words

## How It Works

### Core NLP Pipeline (`marathi_nlp_core.py`)

1. **Tokenization**: Uses regex to split on non-Devanagari, non-alphanumeric characters
2. **Sentiment**: Counts positive/negative lexicon matches, computes score
3. **Emotion**: Counts words across 10 emotion lexicons, finds dominant emotion
4. **POS**: Applies heuristic rules based on token patterns and suffixes
5. **Entities**: Matches tokens against pre-built entity candidate lexicon
6. **TF-IDF**: Transforms input using pre-trained vocabulary, returns top terms
7. **LDA**: Transforms input using CountVectorizer, predicts topic distribution

### Streamlit UI (`app.py`)

- Clean, intuitive interface with 7 analysis sections
- Interactive Plotly visualizations (bar charts, pie charts, gauges)
- Real-time analysis on button click
- Example texts for quick testing

## Troubleshooting

### Models not loading

**Error**: `Warning: Could not load lda_model.joblib`

**Solution**: Run the export cell in the notebook to generate model files.

### TF-IDF pickling error

**Error**: `Can't pickle <function <lambda>>`

**Solution**: The notebook now exports `tfidf_vocab.json` instead of the full vectorizer. The app rebuilds it from vocabulary.

### Missing CSV files

**Error**: `Warning: Could not load sentiment_lexicon.csv`

**Solution**: Run all cells in `NLPFINALSEM.ipynb` to generate all required CSV files.

### Font rendering issues

**Issue**: Devanagari characters not displaying correctly

**Solution**: 
- Install a Devanagari font (Noto Sans Devanagari, Lohit Devanagari)
- Update browser font settings to support Unicode

## Development

### Adding New Features

1. **New Lexicons**: Add CSV files and update `marathi_nlp_core.py` loaders
2. **New Analysis**: Add function to `marathi_nlp_core.py`, integrate into `app.py`
3. **New Visualizations**: Use Plotly Express or Plotly Graph Objects in `app.py`

### Customizing the UI

Edit `app.py` to:
- Change page layout (`st.set_page_config`)
- Add/remove analysis sections
- Modify color schemes in Plotly charts
- Add export functionality (download results as CSV/JSON)
